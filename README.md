# Tameenak — Unified Insurance App Prototype

Tameenak is a mobile app concept that brings multiple insurance companies and their products together in one place. This project includes a Figma prototype, an interactive HTML demonstration, and a design report.

## Project Overview

The concept brings insurance providers and products into one app. The prototype demonstrates a car insurance journey, allowing users to explore providers, review policy plans and optional add-ons, and follow a sample purchase flow.

## Prototype Features

- Account registration and phone verification screens
- Multiple insurance categories
- Car insurance quote form
- Sample provider and policy plan screens
- Side-by-side plan comparison
- Optional coverage add-ons and price summary
- Simulated payment and order confirmation
- Sample order tracking and policy document screens

## Project Files

- `index.html` — interactive HTML demonstration
- `Tameenak_Design_Report.pdf` — design overview, user journey, screen walkthrough, and prototype limitations

## Scope and Limitations

This is a design prototype, not a live insurance service. The providers, prices, policies, and payment flow use sample data. The prototype does not process payments, issue policies, connect to insurers, or save user information.
